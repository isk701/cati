CATI 森林 · GitHub Pages 部署说明
================================

来源：cati-xk-final-check.tar.gz（2026-10-30 18:06，已确认最新版）
内容：纯 HTML/CSS/JS，无后端、无接口、无第三方追踪。

部署步骤：
1. 登录 GitHub，新建一个 public 仓库，例如 cati。
2. 把本目录里的所有文件上传到仓库根目录，确保 index.html 在根目录。
3. 进入仓库 Settings → Pages。
4. Source 选 “Deploy from a branch”，Branch 选 main，目录选 / (root)，保存。
5. 等 1–2 分钟，访问：
   https://你的用户名.github.io/cati/
6. 微信里打开时，通常会先出现“非微信官方网页，继续访问”的提示，
   点继续即可，这不是网站被拦截。

注意：
- 分享链接已改成自动读取当前域名，放在 /cati/ 子路径下也能用。
- GitHub Pages 在国内部分网络下可能较慢或间歇性打不开；
  如果要求国内稳定，建议用腾讯云 CloudBase 或绑定已备案域名。
- 该站点没有问卷上传接口，答案只保存在访问者本机浏览器。
